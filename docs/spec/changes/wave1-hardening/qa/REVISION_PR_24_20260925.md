## Executive Summary

The review found **20 bugs** and **13 spec-gaps or emergent items**. All 20 bugs were fixed in the QA micro-loop, each with a regression test that fails on `4c9b7c0`: BUG-27..46, all RESUELTO. The most serious were four ways past the guards the change exists to enforce:
- a glob or a shell variable got the agent past protect-paths into the release ledger (BUG-27);
- more than ten push and merge forms reached production unseen by the prod-gate (BUG-28);
- one project-wide prod marker approved every change (BUG-41);
- the conditional "si" counted as an approval (BUG-42).

Two further fixes change existing data or real projects: a spec-merge that silently deleted requirements (BUG-45), and two real legacy shapes that the schema made errors, which blocked the prod-gate (BUG-33).

**The security gate stays closed.** Two High spec-gaps about what a production approval proves are open and need the owner's decision:
- F-76: `check_prod` does not verify the evidence.
- F-77: the approval is bound to a change id the agent controls, not to the commits released.

F-79 (a prod approval survives a reopen) belongs to the same decision. QA is **not approved**.
