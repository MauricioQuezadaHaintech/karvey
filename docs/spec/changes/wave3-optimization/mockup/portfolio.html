Drill into one change (L3)

Each listed change carries the command that opens its own read-only dashboard in that repository's local clone; the portfolio prints it and never opens it itself. No command is printed for a repository shown as “not read”.

REQ-W3-079

Column rules

  • Awaited from client: questions owned by the client's stakeholders, and gates waiting for a human approval.
  • Cost: effort recorded in the period; n/a (no effort) when a change has none.
  • Layout: which spec root was found.

A client filter keeps the output to what a meeting with one client needs; the client is matched without regard to case, and other clients are said to be hidden. REQ-W3-078
